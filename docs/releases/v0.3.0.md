# CrealityOS v0.3.0

## Summary

CrealityOS v0.3.0 adds a production-oriented PSD breakdown skill and improves artifact discovery across designer review, workflow planning, and Meegle writeback paths. This version keeps `v0.2.0` intact and is intended to be published as a new release tag.

## Highlights

- Added `workspace/skills/game-asset-psd-breakdown` for game image to PSD workflows.
- Added production PSD rules: lock the requested canvas, prefer clean regenerated assets when cutout quality is poor, create Photoshop JSX, and verify real PSD output when final PSD delivery is requested.
- Added a spec template and helper script for element classification, reusable asset layers, manifests, recomposition previews, overlays, and fidelity reports.
- Improved artifact indexing so prefixed `.md` and `.json` outputs are collected more reliably.
- Improved designer review packet and Meegle writeback artifact selection.
- Improved workflow fallback guidance when the current process is waiting for designer confirmation or a delivery decision.
- Updated package and Workbench version metadata from `0.2.x` to `0.3.x`.

## Notes

- Runtime outputs under `workspace/runs`, `workspace/deliveries`, and `memory` remain ignored by git.
- Existing `v0.2.0` tag must not be modified or force-pushed.
- Publish `v0.3.0` as a new tag after committing this version update.
