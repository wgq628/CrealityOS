# 候选图风格偏移预警

- 项目：`{{ project_key }}`
- 工作项：`{{ work_item_id }}`
- 状态：`{{ status }}`

## 用途

本报告用于生成图登记后、候选图采纳前，做一次本地风格偏移预警。它不替代设计师看图，只读取 `image_generation_results`、创作包、风格迁移/一致性报告、候选图评审和备注，提前暴露可证据化风险。

## 重点检查

- 生成图是否缺失、是否有明确交付候选。
- 备注或评审问题是否命中项目 `do_not` / forbidden rules。
- 候选图评审中的 `style_fit` 是否过低。
- `V03` 等探索方案是否仍受 `K3` 待验证假设约束。
- 风格迁移报告或风格一致性报告是否已经阻塞。

## 安全门

- [ ] 本报告不会调用出图工具，不消耗额度。
- [ ] 本报告不会发布 Meegle、不流转工作项、不覆盖任何文件。
- [ ] 最终采纳、驳回、修正仍由设计师确认后回写。
